# SakuraSensor-Portfolio
# 概要（Overview）
本プロジェクトは、耳の形状（さくら耳）によってTNR(不妊去勢手術により野良猫の繁殖を抑え、数を減らす活動）済みか否かを判別する画像分類モデルです。  
TNRをした日本の野良猫は、耳をV字にカットされます。その耳がさくらのような形をしているため、カットを施された猫は「さくらねこ」と呼ばれています。
保護団体や自治体によるさくらねこの識別作業を支援するため、機械学習モデルを用いて猫の耳カットの有無を自動で分類します。

耳の切り方が浅い、角度が微妙、判断が困難な画像も一部含まれています。 これは現実のTNR現場でも見られる課題であり、学習モデルの汎用性と柔軟性向上のために採用しています。 ただし、画像枚数が少ないため精度に限界がありますので、結果は目安となります。

## 動機・背景
近年、地域猫活動（TNR）の重要性が増す中で、耳カットの有無を目視で確認する作業は手間や時間がかかる現状があります。そのため、自動で判別することにより現場のみなさまの負担を削減できると思い制作いたしました。また、さくらカット忘れによる２度目の捕獲などがあると猫の命にも関わります。さくらカットをしないと判定ができないと強調することで、今後のカット忘れを防ぐことにもつながれば幸いです。
本プロジェクトは、画像分類AIによる支援の可能性を探るものであり、今後は現場のニーズを反映しながら改善・拡張を予定しています。

保護猫活動を少しでも効率化し、現場で働く方々や猫たちの助けになることを目指しております。
